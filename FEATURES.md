# Features

## Core Kanban
- Columns as stages with policy text and optional WIP limits.
- Cards as work items with body, priority, due date, blocked state.
- Pull into a column is refused at WIP unless the actor is a manager.

## Team board
- Card drawer, checklist, comments, activity log.
- Manager dashboard counts, gated calendar, team roles.

## Still next
- Native drag-and-drop, file attachments, swimlanes, avatar upload.
